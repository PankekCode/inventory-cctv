# Dokumentasi API — Website E-Commerce Hablun CCTV & Internal Inventory

Dokumentasi resmi REST API untuk sistem E-Commerce Hablun CCTV (Storefront) dan Sistem Manajemen Stok Internal (Inventory Management).

---

## 📌 Informasi Umum

- **Base URL:** `http://localhost:8000/api`
- **Format Content-Type:** `application/json`
- **Format Accept:** `application/json`
- **Autentikasi Token:** `Bearer <sanctum_token>` (Header `Authorization: Bearer <token>`)

---

#### 1.2 Katalog Produk (Index & Filter)
Mengambil daftar produk katalog dengan pencarian, filter, dan pagination.

- **Endpoint:** `GET /storefront/products`
- **Query Parameters:**
  - `search` (string, opsional): Pencarian nama/deskripsi produk.
  - `category` (string, opsional): Slug kategori (misal: `wireless`, `analog`).
  - `brand` (string, opsional): Slug brand (misal: `ezviz`, `dahua`).
  - `type` (string, opsional): Tipe produk (`wireless` / `analog`).
  - `featured` (boolean, opsional): Filter produk unggulan (`true` / `false`).
  - `min_price` (numeric, opsional): Filter harga minimum.
  - `max_price` (numeric, opsional): Filter harga maksimum.
  - `sort` (string, opsional): Urutan (`latest`, `price_asc`, `price_desc`, `name_asc`).
  - `per_page` (integer, opsional): Jumlah item per halaman (1–48, default: 12).
- **Response Contoh (200 OK):**
```json
{
  "current_page": 1,
  "data": [
    {
      "id": 1,
      "brand_id": 1,
      "name": "EZVIZ H6c 3MP Smart Wi-Fi Camera",
      "slug": "ezviz-h6c-3mp",
      "product_type": "wireless",
      "starting_price": 458000,
      "average_rating": 4.8,
      "review_count": 15,
      "brand": { "id": 1, "name": "EZVIZ", "slug": "ezviz" },
      "images": [{ "id": 1, "path": "products/ezviz-h6c.jpg", "is_primary": true }]
    }
  ],
  "total": 24
}
```

### 2. Autentikasi Nomor HP & OTP WhatsApp

#### 2.1 Minta Kode OTP (Send OTP)
Mengirimkan kode OTP 4-6 digit via WhatsApp Gateway.

- **Endpoint:** `POST /storefront/otp/send`
- **Request Body:**
```json
{
  "phone": "081234567890",
  "purpose": "guest_checkout"
}
```
*Catatan Purpose:* `guest_checkout`, `customer_login`, `customer_register`.

- **Response Contoh (200 OK):**
```json
{
  "message": "Kode OTP berhasil dikirim via WhatsApp.",
  "data": {
    "verification_id": "9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb6d",
    "phone": "+6281234567890",
    "expires_at": "2026-08-07T16:00:00.000000Z"
  }
}
```

---

#### 2.2 Verifikasi Kode OTP
- **Endpoint:** `POST /storefront/otp/verify`
- **Request Body:**
```json
{
  "verification_id": "9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb6d",
  "code": "123456",
  "purpose": "guest_checkout"
}
```

- **Response Contoh (200 OK):**
```json
{
  "message": "Nomor WhatsApp berhasil diverifikasi.",
  "data": {
    "verification_id": "9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb6d",
    "phone": "+6281234567890",
    "verified_at": "2026-08-07T15:45:00.000000Z"
  }
}
```

---

#### 2.3 Login / Register via OTP (Pelanggan)
Mendaftarkan akun baru atau login menggunakan `verification_id` yang sudah terverifikasi OTP.

### 4. Checkout & Lacak Pesanan (Tracking)

#### 4.1 Proses Checkout Pesanan

##### **Aturan Bisnis Checkout:**
1. **Aturan Guest Checkout:**
   - Wajib melampirkan `verification_id` dari WhatsApp OTP (`purpose: guest_checkout`).
   - `payment_method` **diunci khusus `qris`**.
2. **Aturan User Logged-In:**
   - Bebas memilih `payment_method`: `qris`, `bank_transfer`, `gopay`, `ovo`, `shopeepay`.
   - Tidak memerlukan verifikasi OTP ulang.
3. **Kalkulasi Harga:**
   - PPN 0% (`tax_amount: 0`).
   - Tanpa double charge instalasi (biaya jasa terikat pada varian).

- **Endpoint:** `POST /storefront/checkout`
- **Headers:** `Authorization: Bearer <token>` (Opsional untuk Guest, Wajib untuk User Login).
- **Request Body (Guest Checkout):**
```json
{
  "customer_name": "Budi Guest",
  "phone": "081234567890",
  "verification_id": "9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb6d",
  "installation_address": "Jl. Merdeka No. 45, Jakarta Selatan",
  "installation_city": "Jakarta Selatan",
  "installation_date": "2026-08-10",
  "installation_time_slot": "09:00 - 11:00",
  "payment_method": "qris",
  "items": [
    {
      "product_variant_id": 11,
      "quantity": 1
    }
  ]
}
```

- **Request Body (User Logged-In Checkout):**
```json
{
  "customer_name": "Budi Santoso",
  "installation_address": "Jl. Merdeka No. 45, Jakarta Selatan",
  "installation_city": "Jakarta Selatan",
  "installation_date": "2026-08-10",
  "installation_time_slot": "13:00 - 15:00",
  "payment_method": "bank_transfer",
  "items": [
    {
      "product_variant_id": 11,
      "quantity": 1

  ]
}
```

- **Response Contoh (201 Created):**

    "installation_address": "Jl. Merdeka No. 45, Jakarta Selatan",
    "installation_date": "2026-08-10",
    "installation_time_slot": "09:00 - 11:00",
    "status": "awaiting_payment",
    "payment_status": "pending",
    "payment_method": "qris",
    "subtotal": "650000.00",
    "tax_amount": "0.00",
    "grand_total": "650000.00",
    "payments": [
      {
        "gateway": "dummy_qris",
        "payment_url": "https://qris.habluncctv.com/pay/HBL-2026-0001",
        "qris_payload": "00020101021226670016ID.CO.QRIS.WWW...",

      }
    ]
  }
}

### 2. Master Data Management (CRUD)

#### 2.1 Categories Management
- `GET /categories` — List Kategori Barang Internal
- `POST /categories` — Tambah Kategori
- `GET /categories/{id}` — Detail Kategori
- `PUT /categories/{id}` — Update Kategori
- `DELETE /categories/{id}` — Hapus Kategori

#### 2.2 Suppliers / Brands Management
- `GET /suppliers` — List Supplier / Brand Internal
- `POST /suppliers` — Tambah Supplier
- `GET /suppliers/{id}` — Detail Supplier
- `PUT /suppliers/{id}` — Update Supplier
- `DELETE /suppliers/{id}` — Hapus Supplier

#### 2.3 Items Management (Stok Master)
- `GET /items` — List Barang Inventory
- `POST /items` — Tambah Barang Baru
- `GET /items/{id}` — Detail Barang
- `PUT /items/{id}` — Update Barang
- `DELETE /items/{id}` — Hapus Barang
